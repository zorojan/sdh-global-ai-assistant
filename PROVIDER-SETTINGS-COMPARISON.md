# Сравнение настроек провайдеров AI

## Архитектурные различия

### OpenAI - Модульная структура
OpenAI использует специализированные модели для разных задач:

#### Модели OpenAI:
- **Chat Model** (`openai_chat_model`) - для текстовых разговоров
  - `gpt-4o-mini` - основная модель для чата
  - Специализирована на диалоговом взаимодействии
  
- **Speech-to-Text** (`openai_stt_model`) - распознавание речи
  - `gpt-4o-transcribe` - преобразует аудио в текст
  - Поддерживает множественные языки и диалекты
  
- **Text-to-Speech** (`openai_tts_model`) - синтез речи
  - `gpt-4o-mini-tts` - генерирует речь из текста
  - Требует выбор голоса и языка

#### Голосовые настройки OpenAI:
- **Default Voice** (`default_voice`) - выбор голоса для TTS
  - `nova` - рекомендуется для армянского языка
  - `alloy` - нейтральный вариант
  - `echo`, `fable`, `onyx`, `shimmer` - другие опции

- **Default Language** (`default_language`) - язык интерфейса
  - `am` - Հայերեն (армянский) 
  - `en` - English
  - `ru` - Русский
  - `auto` - автоопределение

---

### Gemini - Унифицированная структура
Gemini теперь имеет полноценную поддержку голосовых технологий через Gemini TTS:

#### Модели Gemini:
- **Voice Model** (`default_model`) - для голосовых разговоров
  - `gemini-2.5-flash-preview-native-audio-dialog` - встроенная поддержка аудио
  - Обрабатывает и речь, и текст в одной модели
  
- **Text Model** (`message_dialog_model`) - для текстовых сообщений  
  - `gemini-pro` - основная модель для текста
  - Оптимизирована для быстрых ответов

- **TTS Model** (`gemini_tts_model`) - для синтеза речи
  - `gemini-2.5-flash-tts` - быстрая генерация речи
  - `gemini-2.5-pro-tts` - высококачественная речь

#### Голосовые настройки Gemini:
- **Gemini Voice** (`gemini_default_voice`) - выбор голоса для TTS
  - `Kore` - рекомендуется для армянского языка (женский)
  - `Charon` - мужской голос
  - `Achernar`, `Aoede`, `Despina`, `Leda` - различные женские голоса
  - `Fenrir`, `Puck` - дополнительные мужские голоса

- **Gemini Language** (`gemini_default_language`) - поддержка языков
  - `hy-AM` - Armenian (Հայերեն) - **ПОЛНАЯ ПОДДЕРЖКА АРМЯНСКОГО!**
  - `en-US` - English (United States)
  - `ru-RU` - Russian (Русский)
  - Множество других языков

---

## Общие настройки

### Системные параметры (для всех провайдеров):
- **Enable Audio** (`enable_audio`) - включение аудио функций
- **Max Conversation Length** (`max_conversation_length`) - лимит истории сообщений
- **AI Provider** (`ai_provider`) - выбор основного провайдера

---

## Практические различия

### OpenAI подходит когда нужно:
✅ Точный контроль над голосом и произношением  
✅ Поддержка множественных языков с настройками  
✅ Специализированные модели для разных задач  
✅ Высокое качество синтеза речи на армянском языке  

### Gemini подходит когда нужно:
✅ Простота настройки и использования  
✅ Быстрая обработка без промежуточных этапов  
✅ Нативная поддержка аудио диалогов  
✅ Автоматическое определение языка  
✅ Более экономичное использование API  

### Гибридный режим:
🔄 Позволяет использовать преимущества обоих провайдеров  
🔄 Автоматическое переключение в зависимости от задачи  
🔄 Показывает все настройки для гибкой конфигурации

---

## Рекомендации по выбору

1. **Для армянского языка**: OpenAI с голосом `nova`
2. **Для быстрых чатов**: Gemini с `gemini-pro`  
3. **Для универсальности**: Гибридный режим
4. **Для экономии**: Gemini как основной провайдер
5. **Для качества речи**: OpenAI для голосовых функций
