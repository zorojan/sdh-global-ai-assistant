# 🎯 SDH Global AI Assistant - Обновленная система v4.1.0

*Обновлено: 5 ноября 2025*

## 🚀 Новые возможности в v4.1.0

### ✨ Усиленная мультиязычность
- **Армянский язык (hy-AM):** КРИТИЧЕСКИЕ инструкции для чистого армянского ответа
- **Русский язык (ru-RU):** Строгие правила против английских слов  
- **Английский язык (en-US):** Натуральная речь на английском
- **Предотвращение смешения языков:** Агенты говорят ТОЛЬКО на назначенном языке

### 🎤 Система голосовых характеристик  
- **Индивидуальные настройки голоса** для каждого агента
- **Гибкие инструкции:** тон, темп, эмоции, паузы
- **Интеграция в промпты:** автоматическое включение в системные инструкции
- **Admin панель:** удобное редактирование через веб-интерфейс

### 🏢 Конфигурируемая информация о компании
- **Динамические настройки:** название, описание, сайт, документы
- **Замена hardcoded значений:** больше никаких жестко заданных "SDH Global"  
- **Admin панель управления:** вкладка "О компании" для всех настроек
- **Автоматическое использование:** агенты используют актуальную информацию

## 📋 Быстрый старт

### Установка и запуск:
```bash
# 1. Клонировать репозиторий
git clone https://github.com/zorojan/sdh-global-ai-assistant.git
cd sdh-global-ai-assistant

# 2. Установить зависимости
npm install
cd backend && npm install
cd ../admin-panel && npm install  
cd ../frontend && npm install

# 3. Настроить переменные окружения
cp backend/.env.example backend/.env
# Добавить GEMINI_API_KEY в backend/.env

# 4. Запустить систему
npm run dev
```

### Доступ к системе:
- **Backend API:** http://localhost:3001
- **Admin Panel:** http://localhost:3000  
- **Frontend:** http://localhost:5175

## 🎯 Использование новых функций

### 1. Настройка голосовых характеристик

```bash
# 1. Открыть Admin панель -> Агенты
# 2. Создать/редактировать агента
# 3. В поле "Голосовые характеристики" добавить:
```

**Примеры voice_characteristics:**
```
Дружелюбный тон: "Говорите теплым и дружелюбным тоном. Используйте эмоциональные выражения и положительную интонацию."

Профессиональный: "Поддерживайте формальный и профессиональный тон. Говорите четко, уверенно, избегайте слишком эмоциональных выражений."

Спокойный помощник: "Говорите медленно и спокойно. Делайте паузы между предложениями. Используйте успокаивающий тон."
```

### 2. Настройка мультиязычности

```bash
# 1. Создать агента с языком hy-AM (армянский)
# 2. Система автоматически добавит КРИТИЧЕСКИЕ языковые инструкции
# 3. Агент будет отвечать ТОЛЬКО на армянском языке
```

**Поддерживаемые языки:**
- `hy-AM` - Восточный армянский  
- `ru-RU` - Русский
- `en-US` - Английский

### 3. Управление информацией о компании

```bash
# 1. Открыть Admin панель -> О компании  
# 2. Заполнить поля:
#    - Название компании
#    - Описание компании  
#    - Веб-сайт компании
#    - Корпоративные документы
# 3. Сохранить
# 4. Агенты автоматически будут использовать новую информацию
```

## 🏗️ Архитектура обновлений

### База данных:
```sql
-- Новая колонка в таблице agents
ALTER TABLE agents ADD COLUMN voice_characteristics TEXT;

-- Новые настройки в таблице settings
INSERT INTO settings (key, value, description) VALUES 
('company_name', 'Your Company', 'Company Name'),
('company_description', 'Company Description', 'About Company'),
('company_website', 'https://company.com', 'Company Website'),
('company_documents', 'Company policies...', 'Internal Documents');
```

### API эндпоинты:
```bash
# Агенты с голосовыми характеристиками
GET    /api/agents              # Получить всех агентов
POST   /api/agents              # Создать агента с voice_characteristics
PUT    /api/agents/:id          # Обновить агента с voice_characteristics

# Настройки компании  
GET    /api/settings            # Получить все настройки (включая компанию)
PUT    /api/settings/:key       # Обновить настройку компании
```

### Компоненты:
```
admin-panel/
├── src/components/
│   ├── AgentsTab.tsx           ✅ Поля voice_characteristics
│   └── CompanyTab.tsx          ✅ Управление настройками компании
└── src/app/page.tsx            ✅ Вкладка "О компании"

backend/
├── src/routes/agents.ts        ✅ Языковые инструкции + промпты
└── src/database/init.ts        ✅ Миграции БД

frontend/
└── lib/prompts.ts              ✅ Асинхронные промпты с компанией
```

## 🚨 Важные изменения (Breaking Changes)

### 1. Асинхронные промпты
```typescript
// БЫЛО:
const prompt = createSystemInstructions(agent, user);

// СТАЛО: 
const prompt = await createSystemInstructions(agent, user);
```

### 2. Новая колонка в БД
```sql
-- Требуется миграция (выполняется автоматически при запуске backend)
ALTER TABLE agents ADD COLUMN voice_characteristics TEXT;
```

### 3. Авторизация для настроек
```typescript
// Все запросы к /api/settings теперь требуют авторизационный токен
// Admin панель автоматически добавляет токен через settingsAPI
```
