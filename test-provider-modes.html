🎤 Test Provider Modes

Данная страница тестирует различные режимы провайдера AI:

📋 Инструкция по тестированию

  1. Откройте админ-панель
  2. Установите ai_provider в одно из значений: 'gemini', 'openai', или 'hybrid'
  3. Нажмите кнопки ниже для тестирования каждого режима
  4. Проверьте поведение виджета в режиме voice chat

🤖 Режим Gemini (автоматический выбор)

Ожидаемое поведение: При установке ai_provider = 'gemini' в админке, виджет автоматически использует только Gemini без показа выбора провайдера

⚡ Режим OpenAI (автоматический выбор)

Ожидаемое поведение: При установке ai_provider = 'openai' в админке, виджет автоматически использует только OpenAI без показа выбора провайдера

🔄 Режим Hybrid (выбор пользователя)

Ожидаемое поведение: При установке ai_provider = 'hybrid' в админке, виджет показывает ProviderSelector, пользователь сам выбирает между Gemini/OpenAI
