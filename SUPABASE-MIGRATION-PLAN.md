# План миграции базы данных на Supabase

Этот документ описывает шаги по миграции базы данных приложения с SQLite на Supabase (PostgreSQL).

## 1. Настройка проекта Supabase

1.  **Создайте проект:** Перейдите на [supabase.com](https://supabase.com/) и создайте новый проект.
2.  **Получите учетные данные:** В настройках проекта (`Project Settings` -> `API`) найдите и скопируйте:
    *   **Project URL** (URL проекта)
    *   **`service_role` Key** (Ключ `service_role`)
3.  **Настройте переменные окружения:** Добавьте эти значения в ваш файл `.env` (или в переменные окружения вашей среды выполнения):
    ```
    SUPABASE_URL=ВАШ_URL_ПРОЕКТА
    SUPABASE_SERVICE_KEY=ВАШ_КЛЮЧ_SERVICE_ROLE
    ```

## 2. Установка зависимостей

Добавьте клиентскую библиотеку Supabase в `backend/package.json`:

```bash
cd backend
npm install @supabase/supabase-js
```

## 3. Создание таблиц в Supabase

Используйте редактор SQL в панели управления Supabase для выполнения следующих запросов и создания таблиц.

### Таблица `settings`

```sql
CREATE TABLE IF NOT EXISTS settings (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  key TEXT UNIQUE NOT NULL,
  value TEXT NOT NULL,
  description TEXT,
  type TEXT DEFAULT 'string',
  created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);
```

### Таблица `agents`

```sql
CREATE TABLE IF NOT EXISTS agents (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  personality TEXT NOT NULL,
  body_color TEXT NOT NULL,
  voice TEXT NOT NULL,
  avatar_url TEXT,
  knowledge_base TEXT,
  system_prompt TEXT,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
  language TEXT DEFAULT 'hy-AM',
  voice_language TEXT DEFAULT 'hy-AM',
  voice_characteristics TEXT
);
```

### Таблица `admin_users`

```sql
CREATE TABLE IF NOT EXISTS admin_users (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  username TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  email TEXT,
  last_login TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);
```

## 4. Интеграция клиента Supabase

Создайте новый файл `backend/src/database/supabase.ts` для инициализации клиента Supabase.

```typescript
// backend/src/database/supabase.ts
import { createClient } from '@supabase/supabase-js';
import dotenv from 'dotenv';

dotenv.config();

const supabaseUrl = process.env.SUPABASE_URL;
const supabaseKey = process.env.SUPABASE_SERVICE_KEY;

if (!supabaseUrl || !supabaseKey) {
  throw new Error('Supabase URL and service key are required.');
}

export const supabase = createClient(supabaseUrl, supabaseKey);

console.log('📦 Connected to Supabase');
```

## 5. Скрипт для миграции данных

Создайте скрипт `backend/migrate-to-supabase.js` для переноса данных из SQLite в Supabase.

```javascript
// backend/migrate-to-supabase.js
const sqlite3 = require('sqlite3');
const { createClient } = require('@supabase/supabase-js');
require('dotenv').config();

const DATABASE_PATH = process.env.DATABASE_PATH || './database.sqlite';

const db = new sqlite3.Database(DATABASE_PATH, (err) => {
  if (err) {
    console.error('Error opening SQLite database:', err);
    return;
  }
  console.log('Connected to SQLite database for migration.');
});

const supabase = createClient(process.env.SUPABASE_URL, process.env.SUPABASE_SERVICE_KEY);

const migrateTable = (tableName, transformFn) => {
  return new Promise((resolve, reject) => {
    db.all(`SELECT * FROM ${tableName}`, [], async (err, rows) => {
      if (err) {
        return reject(new Error(`Error reading from ${tableName}: ${err.message}`));
      }

      if (!rows || rows.length === 0) {
        console.log(`No data to migrate for ${tableName}.`);
        return resolve();
      }
      
      const dataToInsert = transformFn ? rows.map(transformFn) : rows;

      const { error } = await supabase.from(tableName).insert(dataToInsert);

      if (error) {
        return reject(new Error(`Error inserting into Supabase table ${tableName}: ${error.message}`));
      }

      console.log(`✅ Successfully migrated ${rows.length} rows to ${tableName}.`);
      resolve();
    });
  });
};

const runMigration = async () => {
  try {
    console.log('Starting data migration...');

    // Migrate settings
    await migrateTable('settings');

    // Migrate agents (handle boolean conversion)
    await migrateTable('agents', (row) => ({
      ...row,
      is_active: Boolean(row.is_active),
    }));

    // Migrate admin_users
    await migrateTable('admin_users');

    console.log('🎉 Data migration completed successfully!');
  } catch (error) {
    console.error('Migration failed:', error);
  } finally {
    db.close();
  }
};

runMigration();

```

**Чтобы запустить миграцию:**

```bash
cd backend
node migrate-to-supabase.js
```

## 6. Обновление кода приложения

Замените логику, использующую `sqlite3`, на вызовы клиента Supabase. Это затронет все CRUD-операции в вашем приложении.

**Пример (до):**

```typescript
// Используя sqlite
db.get('SELECT * FROM settings WHERE key = ?', [key], (err, row) => {
  // ...
});
```

**Пример (после):**

```typescript
// Используя supabase
import { supabase } from './database/supabase';

const { data, error } = await supabase
  .from('settings')
  .select('*')
  .eq('key', key)
  .single();
```

Вам нужно будет найти все вхождения `getDatabase()` и заменить их на `supabase`.
