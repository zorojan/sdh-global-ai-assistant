## ✅ Новая система управления:

### 🎯 Главные команды:
```bat
service-manager.bat    # Интерактивное меню управления
start-all.bat         # Запустить все сервисы
stop-all.bat          # Остановить все сервисы  
restart-all.bat       # Перезапустить все сервисы
```

### 📊 Порты:
- **Backend**: `3001`
- **Frontend**: `5175` 
- **Admin Panel**: `3000`
- **Test Frontend**: `5176`

### 🔧 Что делает система:

#### `service-manager.bat` - Главное меню:
1. Запуск всех сервисов
2. Остановка всех сервисов
3. Перезапуск всех сервисов
4. Запуск отдельного сервиса
5. Проверка статуса
6. Открытие всех URL
7. Выход

#### `start-all.bat` - Умный запуск:
- Автоматически останавливает старые процессы
- Запускает все сервисы по очереди
- Проверяет порты
- Открывает URL в браузере

#### `stop-all.bat` - Полная очистка:
- Убивает все Node.js процессы
- Освобождает все порты
- Очищает зависшие процессы

### 🚫 Защита от ошибок:
- `npm run dev` в корне теперь показывает ошибку
- Автоматическая очистка портов
- Проверка статуса сервисов

## 🎮 Как использовать:

### Быстрый старт:
```bat
# Двойной клик или в терминале:
service-manager.bat
```

### Прямые команды:
